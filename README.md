# 공공주거 길잡이 (public-housing-guide)

청년이 공공임대주택 공고를 찾고, 이해하고, 신청 일정을 놓치지 않도록 돕는 서비스의 시연용 프로토타입입니다.

## 서비스 소개

공공임대주택 공고는 공급 기관마다 게시 위치와 형식이 다르고, 신청 자격과 용어가 어려워 청년이 스스로 판단하기 어렵습니다. 접수, 서류 제출, 당첨자 발표, 계약까지 일정이 여러 단계로 이어져 중요한 날짜를 놓치는 경우도 많습니다.

공공주거 길잡이는 이 과정을 한곳에서 안내합니다. 내 조건에 맞는 공고를 찾고, 공고 내용을 쉬운 말로 확인하고, 신청 일정을 캘린더로 관리할 수 있습니다.

## 주요 기능

| 번호 | 기능 | 설명 |
|---|---|---|
| 01 | 랜딩 페이지, 아웃 페이지 | 서비스를 소개하는 첫 화면과 이용을 마무리하는 마지막 화면입니다. |
| 02 | 주거지원 자가진단 | 9개 질문에 답하면 현재 모집 중인 공고 가운데 내 조건에 맞는 공고를 보여줍니다. |
| 03 | AI 공고 설명 | 공고 링크를 등록하면 신청 자격, 일정, 임대 조건을 정리하고 어려운 용어를 설명합니다. |
| 04 | 캘린더 대시보드 | 등록한 공고의 접수, 발표, 계약 일정을 월간 캘린더로 보여줍니다. |
| 05 | 주거트래커 | 공고별 진행 단계와 결과를 기록하고 다음 할 일을 안내합니다. |

## 이용 흐름

랜딩 페이지에서 시작합니다. 서비스 화면에서는 왼쪽 메뉴로 자가진단, 공고 추가, 캘린더 대시보드, 주거트래커를 오갈 수 있으며, 아웃 페이지에서 이용을 마칩니다.

## 프로토타입 보기

저장소 최상위의 index.html을 브라우저로 열면 랜딩 페이지에서 시연을 시작합니다. 기능별 화면 목록은 각 폴더의 SCREENS.md에서 확인할 수 있습니다.

## 폴더 구조

    public-housing-guide/
    ├── index.html                 시연 시작 (랜딩 페이지로 이동)
    ├── shared/                    공통 스타일, 왼쪽 메뉴, 예시 데이터
    ├── 01-landing-outro/          랜딩 페이지, 아웃 페이지
    ├── 02-self-diagnosis/         주거지원 자가진단
    ├── 03-notice-summary/         AI 공고 설명
    ├── 04-schedule-calendar/      캘린더 대시보드
    ├── 05-housing-tracker/        주거트래커
    ├── README.md
    └── AGENTS.md                  프로토타입 업로드 규칙

## 유의 사항

이 저장소는 시연용 프로토타입으로, 실제 서버와 데이터베이스는 구현하지 않습니다. 화면에 표시되는 공고 정보는 예시이며, 실제 공고를 인용한 경우 출처와 기준일을 함께 표기합니다. 최종 신청 자격은 각 공고문과 공급 기관에서 확인해야 합니다.

## 기여 방법

프로토타입을 추가하거나 수정할 때는 AGENTS.md의 규칙을 따릅니다. AI 도구를 사용하는 경우 이 저장소 주소를 전달하면 AI가 README.md와 AGENTS.md를 읽고 같은 규칙으로 작업합니다.
